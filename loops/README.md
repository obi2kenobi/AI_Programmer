# loops/ — i log dei loop /goal

Ogni file è un loop di ottimizzazione diurno: `<data>-<slug>.md` con un tentativo per sezione
(modifica fatta → risultato verifica). L'artefatto di tracciabilità che il metodo richiede:
chi legge vede la strada, non solo l'arrivo. Regola dal comando /goal: verifica dichiarata col
suo livello (1-5), tetto di tentativi, verifica avversariale prima della vittoria.
