# Strategia di backup (13/11/2026)
1. TUTTO ciò che è in git → push (fatto)
2. Config OpenClaw (~/.openclaw/) → copia in repo privato o Time Machine
3. Modelli Ollama → scaricabili di nuovo (non si backkkupano, si re-pull)
4. Workspace openclaw-lab/ → git push se repo, Time Machine se no
5. Time Machine: ATTIVO di default su macOS → verificare disco
