Crea una commessa per il turno di notte: **$ARGUMENTS**

## Il wizard (una domanda per volta, poi componi)

1. **Quale repo?** (owner/name — se vuota, leggi night-shift/repos.conf del hub)
2. **Cosa vuoi che faccia?** (riformula in una frase verificabile)
3. **Da dove nasce?** (se esiste già un design-doc per questa idea — `/design-doc`, opzioni
   confrontate su criteri espliciti e già scelte — CITA IL SUO PERCORSO qui, non riscriverlo
   a memoria; altrimenti link a SAL/issue/analisi. Se non sai, FERMATI: il design richiede
   il da-dove, e da questo giro deve essere un riferimento VERO — il gate non accetta più
   solo la lunghezza)
4. **Che file/RIGHE servono?** (usa graphify o grep per trovarli — il territorio va dichiarato con precisione)
5. **Che forma hanno i dati?** (apri il file e VERIFICA: campi, aggregazioni, dove vivono davvero)
6. **Come si verifica, e a quale livello?** (comando eseguibile nel gate, o "banco
   avversariale + review umana" — E il livello 1-5 di `docs/system.md` §"I cinque
   livelli di verifica": 1 deterministico, 2 regole/soglie numeriche, 3 verità
   terrena ritardata, 4 LLM giudice, 5 checkpoint umano. Stessa tassonomia che `/goal`
   richiede di dichiarare — 5° ciclo, set 2 giro 4, 2026-08-23: prima il wizard
   chiedeva "come" ma non "quale livello", disallineato dalla stessa tassonomia che
   il resto del sistema già usa)

## Componi l'issue

```bash
gh issue create -R <repo> --label night-shift --title "<titolo chiaro>" --body <file>
```

Il body DEVE avere le sezioni nell'ordine: ## Design (con il da-dove) · ## Territorio (file e dimensione) · ## Forma dei dati (verificata sul codice) · ## Commessa (punti esatti) · ## Verifica (livello dichiarato).

## Controllo qualità prima di inviare

- [ ] Design ≥ 80 caratteri utili E con un riferimento vero (link, SAL.md, issue #N, o
      file — il gate del set 2 2026-08-22 non accetta più prosa senza fonte)
- [ ] Territorio nomina almeno un file (il gate lo verifica)
- [ ] Se il territorio è GRANDE (file da centinaia di righe): NON inviare — passa al giorno
- [ ] La forma dei dati è VERIFICATA (hai aperto il file, non lo hai assunto)
